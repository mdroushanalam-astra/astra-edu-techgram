# Final artwork prompt set

Built-in `image_gen.imagegen` was used for every original image. The founder's UI board was supplied as a style/composition reference; all assets are text-free. Transparent requests used the tool's transparency flag. Final application assets are saved in `apps/web/public/art/`. The original generated PNGs remain in the Codex generated-images directory; WebP export preserves character alpha.

## home.webp (+ home-mobile.webp)

Use case: stylized-concept. Reference image is visual style reference only. Generate a text-free cinematic study room background asset, wide 16:9 composition. Closely match panel 6 of the reference: warm amber desk lamps, wooden desk in foreground, bookshelves left, lush potted plants, night city skyline and crescent moon through tall window at center, sleeping dark cat on desk bottom left. Rich polished illustrated 3D animation aesthetic, navy shadows, orange amber highlights. No characters, no orb, no text, no logos, no UI panels. Leave middle/right desk and room area spacious for coded UI overlays. Save as project background asset.
